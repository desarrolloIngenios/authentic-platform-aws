# Architecture Decision Records

Los archivos ADR deben seguir el formato:

1. Estado.
2. Contexto.
3. Decisión requerida.
4. Alternativas.
5. Comparación técnica y económica.
6. Riesgos.
7. Decisión.
8. Consecuencias.
9. Estrategia de reversión.

ADRs obligatorios antes de implementación:

- Plataforma Kubernetes: EKS versus EC2 autoadministrado.
- CNI y networking.
- Load Balancer.
- Persistencia y backup.
- Secretos.
- Objetos y registro de imágenes.
- Observabilidad.
